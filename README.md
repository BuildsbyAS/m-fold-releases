# M-Fold

A little magic when you close your MacBook.

M-Fold holds your desktop image in place as the lid moves, adding perspective, progressive blur and soft shading.

## Downloads

Official installers and release notes will appear in [Releases](https://github.com/BuildsbyAS/m-fold-releases/releases).

**No public release is available yet.** Signed in-app updates are being prepared.

## Materials

- **Original** — clear glass and quiet edges.
- **Vellum** — warm paper and soft diffusion.
- **Afterglow** — deeper shading and a warm reflected rim.

## Requirements

- macOS 26 or later
- An Apple-silicon MacBook with a supported lid-angle sensor
- Screen Recording permission for the desktop effect

A sample preview works without Screen Recording permission. External displays remain unchanged.

## Privacy

Captured desktop frames stay on your Mac and are never saved or uploaded. No accounts, analytics or telemetry.

Once configured, optional update checks contact GitHub to retrieve release information and approved downloads.

## Updates

M-Fold includes an in-app updater. Background checks are opt-in; downloading and installing an update require your approval.

The first updater-enabled release will need to be installed manually.

## About this repository

This repository hosts official downloads, release notes and the signed update feed. The app’s source code is maintained separately.

M-Fold is an independent project and is not affiliated with Apple or Bendy.
